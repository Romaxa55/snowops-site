# SnowOps — дизайн-система сайта

Сайт одиночного стелс-шутера SnowOps: заснеженная военная база, охрана живёт по уставу, один оперативник. Аудитория — игроки 16+, телефон и ПК. Сайт устроен **как игра**: один экран без прокрутки, главное меню, экраны разделов, HUD. Задача — показать игру честно (только настоящие кадры и правдивые тексты) и довести до скачивания.

## Что здесь

- `tokens/` — палитра и типографика. Переменные живут в `game.css` (`:root`), они уже вшиты в каждое превью.
- `fonts/` — Tektur 500/700 (логотип, заголовки экранов, пункты меню), Geist 400–600 (текст, кнопки), Geist Mono 400–500 (метки, HUD, счётчики). Латиница и кириллица, OFL, локально.
- `components/` — главное меню, вкладки и нижняя полоса, шторка смены экрана, камера с донесениями, пульт охраны, слоты снаряжения, документ, QR-карточка.
- `pages/` — главная целиком (живая, со скриптом: меню, экраны, звук) и страница документа.
- `assets/` — настоящие кадры из игры (WebP 1600/800), обложка для соцсетей, звуки меню.

## Главные приёмы

1. **Сайт — игра.** Главное меню поверх кадра. Выбор пункта — смена экрана шторкой «Загрузка · 02 / 05» с расшифровкой заголовка. Вкладки Q/E, Esc — в меню, ←/→, ◀ ▶ и свайп листают внутри экрана. Без прокрутки на 360×640…1440×900, на телефоне длинное разбито на страницы.
2. **Камеры вместо галерей.** Кадры показаны через монитор наблюдения: REC, «КАМ 03 · Вышка», часы, «?» или «!», помеха при переключении, включение по очереди на пульте.
3. **Досье вместо витрины.** Брифинг — бумага со скрепкой и штампом, документы — оглавление в рамке «целей миссии», пункты с красными метками.
4. **Снаряжение вместо списка ссылок.** Платформы — слоты с характеристиками и размерами из последнего релиза, слот вашей системы — первым, с плашкой.

## Принципы

1. Один акцент — красный: действие («Начать миссию», «Взять»), тревога («!»), REC, выбор. Янтарь — только «?».
2. Tektur — только логотип, заголовки экранов и пункты меню, капсом. Текст — Geist. Всё служебное (метки, счётчики, HUD) — Geist Mono капсом с разрядкой.
3. Только правда: кадры сняты в игре без доработки, тексты сверены с кодом игры. Чего в игре нет, на сайте нет.
4. Движение служит игре: смена экрана, расшифровка, включение камер, наезд на меню. Всё выключается при `prefers-reduced-motion`.
5. Звук — из игры: свист прыжка на смену экрана, ревун на «Начать миссию», створки рампы после загрузки, щелчки меню и помехи синтезом; музыка — тема автора. Включается с первого нажатия, кнопки «Музыка» и «Звук».
6. Оригинал, по мотивам которого сделана игра, на сайте не упоминается.
