# Трейлер SnowOps — сценарий

Длительность 45 секунд, 16:9, 1920×1080, 30 fps. Без закадрового голоса, без текста поверх геймплея, кроме двух титров. Музыка: трек из Suno (вариант 1), удар должен лечь на 0:20.

Источники кадров:
- **GP** — запись игры: `godot --path ../snowops-game --write-movie trailer/gp/take01.avi --fixed-fps 30` (или экспортированная macOS-сборка + запись экрана). Играем сами, по сценарию ниже.
- **ST** — статичные арты из `assets/img/shots/*.jpg`, оживлённые в ffmpeg (медленный наезд 4–6 %, лёгкая панорама, поверх снег).
- **TC** — титры, рендер из `trailer/title/*.html` в PNG.

Правила монтажа:
- Геймплей без HUD, если движок позволяет его скрыть; иначе HUD оставляем, это честно для стора.
- Ни одного кадра с надписями из игры на экране (меню, субтитры).
- Между ST и GP — жёсткие склейки, без наплывов; наплыв только в чёрное на 0:20 и 0:35.
- Цветокор всего материала в одну сторону: холодный синий, лёгкое виньетирование, зерно 3–5 %.
- Для магазинов дополнительно режем вертикальную версию 9:16 из тех же клипов (центр-кроп, титры перевёрстываются).

Сборка: `trailer/assemble.sh` (появится вместе с первыми клипами) склеивает по этому списку, накладывает `trailer/audio/*.mp3|wav`, выдаёт `trailer/snowops-trailer.mp4`, на который уже ссылается `index.html`.
